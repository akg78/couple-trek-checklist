# Ankit & Baishakhi — Trek Checklist

Mobile checklist for **Tungnath → Chandrashila**. Data lives in **localStorage** (no server, no `.env`).

```bash
npm install
npm run dev
```

**Deploy:** push to GitHub → import on [Vercel](https://vercel.com) → deploy (no env vars).

**Sync between phones:** Share backup → WhatsApp → Import backup on the other device.
